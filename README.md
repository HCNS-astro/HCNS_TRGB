# HCNS_TRGB

## Install

Requires Python 3.10+.

```sh
git clone https://github.com/HCNS-astro/HCNS_TRGB.git
cd HCNS_TRGB
pip install -r requirements.txt
```

## Run

```sh
python3 trgb_gui.py     
```

## Load Galaxies
To load galaxies, download photometry from the box folder and put them in the galaxies/ folder.
